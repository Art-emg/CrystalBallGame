# Crystal Orbit

Готовая браузерная 3D-головоломка по мотивам механики Crystal Marble Puzzle. Проект полностью независим от Unity и рассчитан на обычный браузер, мобильные устройства и публикацию в Яндекс Играх.

## Что реализовано

- 100 уровней с разными векторными силуэтами;
- математически гарантированное размещение всех частиц внутри сферы;
- вращение мышью, пальцем и стрелками клавиатуры;
- мягкое распознавание решения и анимация завершения;
- три подсказки на уровень, последовательно приближающие сферу к решению;
- адаптивный интерфейс для телефонов и десктопов;
- локальное и облачное сохранение прогресса;
- интеграция Yandex Games SDK: Game Ready, Gameplay API, пауза и полноэкранная реклама между уровнями;
- синтезированные звуки без внешних аудиофайлов.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Готовые статические файлы появляются в `dist`. Для Яндекс Игр нужно загрузить ZIP-архив, в корне которого находится `index.html`. Готовый архив также создаётся рядом с проектом как `crystal-orbit-yandex.zip`.

## Как добавлять уровни

Список находится в `src/game/levels.ts`. Добавьте новый заполненный SVG path из совместимого набора и название — облако частиц, глубина, случайное начальное вращение и распознавание создаются автоматически.

## Архитектура

- `src/game/CrystalScene.tsx` — Three.js-сцена, генерация частиц и вращение;
- `src/game/levels.ts` — каталог 100 силуэтов;
- `src/game/yandex.ts` — безопасная интеграция SDK с браузерным fallback;
- `src/App.tsx` — игровой цикл, прогресс, подсказки и UI.
